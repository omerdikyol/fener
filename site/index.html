    01 · Answers

    Type the question, not the app. Math, units, currencies, time zones and dates resolve while you type. Return copies the result.

    02 · Menus

    Anything you can run in a shell is a menu entry. A few lines of TOML, or a script that prints choices, become a menu with icons, submenus and confirmations.

    ~/.config/fener/menus/capture.toml
    [[entry]]
name = "Region to Clipboard"
icon = "nf-md-selection_drag"
command = "screencapture -i -c"

[[entry]]
name = "Window to Desktop"
icon = "nf-md-window_maximize"
command = "screencapture -i -W ~/Desktop/shot.png"

[[entry]]
name = "Record or More…"
subtitle = "Screenshot app"
command = "open -a Screenshot"

    03 · Configuration

    Every setting is a line in a file. Save config.toml and fener applies it. Prefer clicking? The same settings are in the panel, written back with your comments kept.

    ~/.config/fener/config.toml
    theme =    # click it
shortcut = "cmd+space"

[panel]
position = "center"
screen = "mouse"

[clipboard]
keep_days = 30
ignore_apps = ["1Password"]

    Get fener

    Homebrew

    Installs the app and the fener command. brew upgrade keeps it current.

    brew install --cask omerdikyol/tap/fener

    Download

    Signed and notarized. Open the disk image, drag fener to Applications and open it. It adds itself to Login Items.

    Download fener.dmg

    Build from source

    Needs Xcode or the Command Line Tools. Installs the app, the fener command and a login item.

    git clone https://github.com/omerdikyol/fener && fener/scripts/install.sh

    Then

    Turn off Spotlight's ⌘ space in System Settings › Keyboard › Keyboard Shortcuts, or pick another shortcut in fener Settings. Icons need a Nerd Font:

    brew install --cask font-jetbrains-mono-nerd-font

    fener means lantern in Turkish.
