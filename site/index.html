A launcher you configure in text.

fener opens with one shortcut and finds your apps, files, clipboard history and emoji. It answers sums, conversions and time zones while you type, and turns any shell command into a menu entry. Everything it does is set in plain files under ~/.config/fener.

Download for macOS or build from source

    Your settings are a file

    Change a line, save, and fener applies it. No restart. Every option sits in config.toml, with its default and a comment in config.reference.toml next to it. If you would rather click, the same settings are in the panel, and fener writes them back to the file with your comments kept.

    Menus are files too. A list of commands in TOML, or a script that prints lines and runs again with the one you pick. Keep the folder in your dotfiles.

    Click the theme name in the file.

    ~/.config/fener/config.toml
    # every key is optional
theme = 
shortcut = "cmd+space"

[panel]
position = "center"
close_on_blur = true
    ~/.config/fener/menus/capture.toml
    [[entry]]
name = "Region to Clipboard"
icon = "nf-md-selection_drag"
command = "screencapture -i -c"

[[entry]]
name = "Record or More…"
subtitle = "Screenshot app"
command = "open -a Screenshot"

    What leaves your Mac

    networkOne request: the European Central Bank's public exchange-rate file, at most once a day, only when you convert a currency. Turn it off with [currency] enabled = false.
    telemetryNone. No analytics, no crash reports, no update checks.
    accountNone.
    clipboardStays on your Mac, encrypted with AES-GCM under a key in your Keychain. Password managers' copies are skipped.
    permissionsNone up front. No Accessibility, Input Monitoring or Screen Recording.
    this pageNo trackers, and no fonts or scripts from anywhere else.

    Install

    1. Download the latest release, unzip it and move fener.app to Applications.
    2. Open it. The panel appears and fener adds itself to Login Items.
    3. Press ⌘ Space, after turning off Spotlight's shortcut in System Settings › Keyboard › Keyboard Shortcuts. Or set another shortcut in fener Settings.

    Or build it yourself, with Xcode or the Command Line Tools:

    git clone https://github.com/omerdikyol/fener.git
cd fener && ./scripts/install.sh

    Icons use a Nerd Font: brew install --cask font-jetbrains-mono-nerd-font
